# ADR 030 — Licença pública MIT

## Status

Aceito em 10 de outubro de 2026.

## Contexto

O Chrono Project passou a ser apresentado publicamente em português do Brasil e
inglês. Sem uma licença explícita, visitantes podem ler o repositório, mas não
recebem autorização clara para usar, modificar ou redistribuir o código.

## Decisão

Publicar o código autoral do Chrono Project sob a licença MIT, com titularidade
de Jean Machado e dos contribuidores do projeto. A declaração canônica fica no
arquivo `LICENSE`; os manifestos npm e Cargo usam o identificador SPDX `MIT`.

A licença do projeto não substitui as licenças de dependências, catálogos ou
outros materiais de terceiros. Essas atribuições continuam documentadas em
`THIRD_PARTY_NOTICES.md`.

## Consequências

- uso, cópia, modificação e redistribuição ficam permitidos sob os termos MIT;
- cópias ou partes substanciais devem preservar o aviso de copyright e a licença;
- o software permanece fornecido sem garantia;
- contribuições aceitas serão distribuídas sob a mesma licença do projeto;
- o repositório pode ser identificado como open source depois que o arquivo
  `LICENSE` estiver publicado na branch padrão.
