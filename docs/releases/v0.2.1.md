# Chrono Project v0.2.1

A versão 0.2.1 apresenta a identidade visual definitiva do Chrono Project e
refina a navegação lateral para deixar a interface mais limpa e reconhecível.

## Destaques

- novo símbolo original inspirado em relógios mecânicos, construído como um
  `C` aberto e sem reproduzir a identidade de Chrono Trigger;
- mostrador coerente, engrenagens e acabamento dourado com leitura preservada
  em tamanhos reduzidos;
- novo ícone no aplicativo, executável, instaladores e integrações do Windows;
- remoção do marcador provisório `PF`;
- remoção da repetição do nome `Chrono Project` na barra lateral;
- barra recolhida com acesso pelo próprio símbolo da aplicação.

## Compatibilidade e dados

O schema SQLite continua na versão 5 e o pacote `.chronoproject` continua no
formato 1. A atualização sobre a versão 0.2.0 preserva o banco e os dados locais
do usuário. Não há mudança nas regras de scheduling.

## Instalação

- instalador padrão: `Chrono-Project-Windows-x64-Setup.exe`;
- instalador sem internet: `Chrono-Project-Windows-x64-Offline-Setup.exe`.

O instalador offline inclui a estratégia necessária para máquinas sem acesso
ao WebView2 pela rede. Node.js, Rust, Git e ferramentas de compilação não são
requisitos do usuário final.
