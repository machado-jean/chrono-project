# ProjectFlow v0.1.5

Esta versão consolida a infraestrutura de testes e a documentação de
atualização do ProjectFlow. O schema SQLite permanece na versão 4.

## Melhorias

- Testes desktop com banco, logs e perfis WebView2 isolados por execução.
- Porta de automação dinâmica e verificação do encerramento dos processos.
- Cobertura de aberturas repetidas, execução duplicada e recuperação após
  interrupção.
- Jornada real de planejamento, exportação/importação e persistência após
  reabrir o aplicativo.
- Testes da interface para erros de download e assinatura sem reinício.
- Documentação atualizada do Gantt e do updater passivo assinado.

## Instalação e atualização

Use `ProjectFlow-Windows-x64-Setup.exe` para instalação padrão, ou
`ProjectFlow-Windows-x64-Offline-Setup.exe` para instalar sem internet.
Em versões com updater integrado, use **Ajuda > Verificar atualizações**.
Faça um backup antes de atualizar. O banco fica separado dos binários.

Os arquivos `.sig` são assinaturas do updater Tauri. Os instaladores não
possuem Authenticode e o Windows pode mostrar aviso de editor desconhecido.

## Validação e limites

As suites locais cobrem domínio/interface, SQLite, desempenho e janela Tauri
real. A execução desktop permanece diagnóstica no CI até completar duas
execuções remotas e a validação em VM. Os testes simulados de updater não
substituem a instalação real. A atualização para v0.1.4 foi relatada como
bem-sucedida pelo usuário; v0.1.4 → v0.1.5 será validada após publicação.
