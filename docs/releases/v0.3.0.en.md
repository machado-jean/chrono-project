# Chrono Project v0.3.0

Version 0.3.0 makes Chrono Project bilingual, strengthens dependency-chain
security, and fully preserves existing local data.

## Highlights

- the interface is available in Portuguese (Brazil) and English; on first
  launch, a supported system language is selected and subsequent launches use
  the device-local saved preference;
- menus, actions, filters, messages, help, context menus, and all three views
  are localized; PDF reports use the active interface language;
- the Brazilian holiday catalog is now internal, deterministic, and offline,
  retaining national, state, and moveable holidays, plus manually registered
  municipal holidays;
- the vulnerable transitive `deepmerge` dependency is no longer in the
  production dependency chain; `minimatch` is overridden to 11.0.4;
- CI now uses Node.js 26.13.0 and blocks npm vulnerabilities rated low or
  higher.

## Compatibility and data

There is no SQLite migration or schema change. Existing projects, backups, and
`.chronoproject` packages remain compatible. The `chronoproject` data directory
is unchanged.

## Validation

- lint, typecheck, and 202 TypeScript/React tests passed;
- the application E2E journey passed;
- 39 Rust tests passed and one historical test remains explicitly ignored;
- three performance budgets passed;
- Cargo fmt, check, and Clippy passed;
- npm audit found no known vulnerabilities;
- manual language-switching and holiday-catalog validation passed.
