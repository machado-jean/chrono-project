# Chrono Project v0.2.4

A versão 0.2.4 melhora o uso da Tabela em projetos com títulos longos e coloca
a exportação de projeto diretamente no menu de contexto da barra lateral.

## Destaques

- a coluna **Tarefa** inicia com 380 pixels e pode ser ajustada entre 300 e 760
  pixels arrastando sua borda direita;
- o ajuste também funciona pelas setas do teclado, é preservado entre
  execuções e pode ser restaurado por duplo clique;
- os cabeçalhos **Prioridade**, **Progresso**, **Duração** e **Prazo-limite**
  receberam espaço suficiente para o título e o botão de informação;
- o clique direito em um projeto oferece **Exportar projeto…**, com confirmação
  do caminho salvo;
- o pacote gerado usa o mesmo formato `.chronoproject` aceito por
  **Arquivo > Importar pacote**;
- `source-map-js` foi atualizado para 1.2.2 no lockfile, eliminando a
  vulnerabilidade alta identificada pela auditoria npm.

## Compatibilidade e dados

O schema SQLite permanece em `8` e o formato `.chronoproject` permanece na
versão `1`. Não há migration nesta atualização. Projetos, tarefas,
dependências, calendários, templates, linhas de base e backups da v0.2.3
continuam compatíveis.

A preferência de largura da coluna **Tarefa** é apenas visual e fica no
armazenamento local do aplicativo. Ela não altera nem integra o banco do
workspace ou os pacotes exportados.

## Instalação

- `Chrono-Project-Windows-x64-Setup.exe`: instalador padrão, indicado para
  computadores que já possuem WebView2 ou têm acesso à internet;
- `Chrono-Project-Windows-x64-Offline-Setup.exe`: instalador autocontido para
  computadores sem acesso à internet durante a instalação.

Node.js, Rust, Git e ferramentas de compilação não são requisitos do usuário
final. Os arquivos `.sig`, `latest.json` e `SHA256SUMS.txt` permitem validar a
origem e a integridade dos artefatos.

## Validação

Foram aprovados 173 testes TypeScript/React, 39 testes Rust, a jornada E2E, os
dois testes de desempenho, lint, typecheck, Cargo fmt/check/Clippy, build web e
auditoria npm sem vulnerabilidades conhecidas. O teste Rust que exige uma base
v0.2.1 externa continua explicitamente ignorado e já possui validação manual
histórica.
