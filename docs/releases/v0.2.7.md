# Chrono Project v0.2.7

A versão 0.2.7 prepara a distribuição pública do Chrono Project e melhora a
identificação do aplicativo no Windows. Este candidato também consolida a
governança aberta e bilíngue do repositório.

## Destaques

- o instalador e a entrada em **Aplicativos instalados** passam a exibir
  `Jean Machado` como editor;
- instalação e desinstalação silenciosas pelo NSIS foram validadas com `/S`;
- distribuição futura pelo WinGet foi preparada com o identificador permanente
  `ChronoProject.ChronoProject`;
- licença MIT, formulários de Issue, contribuição, segurança, suporte, código
  de conduta, template de Pull Request e Dependabot foram consolidados;
- READMEs PT-BR e EN apresentam o produto, downloads e documentação de forma
  consistente;
- a configuração do Dependabot evita atualizações incompatíveis ou não
  coordenadas das stacks TypeScript, SQLite e Tauri.

## Compatibilidade e dados

Não há alteração funcional no scheduler nem no modelo de dados. O schema
SQLite permanece na versão `9`, o formato `.chronoproject` permanece na versão
`1` e o identificador de dados continua `chronoproject`.

Atualizar ou reinstalar o aplicativo não deve remover o banco do usuário. O
teste silencioso preservou, sem alteração de hash, uma base legada existente em
`%APPDATA%\io.github.machadojean.chronoproject`.

## Instalação

- `Chrono-Project-Windows-x64-Setup.exe`: instalador padrão para computadores
  com WebView2 ou acesso à internet;
- `Chrono-Project-Windows-x64-Offline-Setup.exe`: instalador autocontido para
  instalação sem internet;
- instalação silenciosa: `Chrono-Project-Windows-x64-Setup.exe /S`;
- desinstalação silenciosa: executar o `uninstall.exe /S` registrado pelo
  Windows para o Chrono Project.

O fluxo silencioso foi aprovado: instalação da v0.2.7, registro do editor
`Jean Machado`, remoção sem interface e reinstalação. Node.js, Rust, Git e
ferramentas de compilação não são requisitos do usuário final.

## Assinaturas e confiança do Windows

Os arquivos `.sig` são assinaturas do atualizador Tauri e foram verificados
contra a chave pública incorporada. Eles não são assinaturas Authenticode.

Os executáveis deste release não recebem certificado comercial. Certificado de
código será considerado somente por uma alternativa gratuita, confiável e
adequada a projeto open source; uma assinatura autoassinada não elimina o aviso
de editor desconhecido em outros computadores.

## Validação

Foram aprovados 191 testes TypeScript/React, 39 testes Rust, uma jornada E2E,
dois testes de desempenho, lint, typecheck, Cargo fmt/check/Clippy e auditoria
npm sem vulnerabilidades conhecidas. O teste Rust que exige uma base v0.2.1
externa permanece explicitamente ignorado e possui validação histórica.

O executável de distribuição foi compilado sem `shared-dev-data`. Os dois
instaladores foram assinados com a chave do updater e o fluxo silencioso foi
validado sobre o instalador padrão. O instalador offline reutilizou os caches de
NSIS e WebView2 e concluiu sem novo download.
