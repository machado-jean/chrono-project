# Chrono Project v0.3.0

A versão 0.3.0 torna o Chrono Project bilíngue, reforça a segurança da cadeia
de dependências e preserva integralmente os dados locais existentes.

## Destaques

- interface disponível em Português (Brasil) e English; na primeira abertura,
  o idioma acompanha o sistema quando ele é compatível e, depois, respeita a
  preferência salva no dispositivo;
- menus, ações, filtros, mensagens, ajuda, menus de contexto e as três
  visualizações foram localizados; o relatório PDF é gerado no idioma ativo;
- o catálogo de feriados brasileiros passou a ser interno, determinístico e
  offline, mantendo feriados nacionais, estaduais, móveis e feriados municipais
  cadastrados manualmente;
- a dependência vulnerável transitiva `deepmerge` deixou de fazer parte da
  cadeia de produção; `minimatch` recebeu override para 11.0.4;
- o CI passou a usar Node.js 26.13.0 e bloqueia vulnerabilidades npm de nível
  baixo ou superior.

## Compatibilidade e dados

Não há migration nem mudança de schema SQLite. Projetos, backups e pacotes
`.chronoproject` existentes continuam compatíveis. O diretório de dados
`chronoproject` não foi alterado.

## Validação

- lint, typecheck e 202 testes TypeScript/React aprovados;
- jornada E2E da aplicação aprovada;
- 39 testes Rust aprovados e 1 teste histórico explicitamente ignorado;
- três orçamentos de desempenho aprovados;
- Cargo fmt, check e Clippy aprovados;
- auditoria npm sem vulnerabilidades conhecidas;
- validação manual aprovada para troca de idioma e catálogo de feriados.
