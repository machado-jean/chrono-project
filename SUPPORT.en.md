# Support

## Where to get help

1. Read the [README](README.en.md), [user guide](docs/user-guide.md), and
   [troubleshooting guide](docs/troubleshooting.md).
2. Search for an existing Issue or Discussion.
3. For usage questions, open a Discussion in **Q&A**.
4. For a reproducible error, use the **Report a bug** form.
5. For an improvement, use the **Suggest an improvement** form.
6. For vulnerabilities, follow [SECURITY.md](SECURITY.en.md) and do not open an
   Issue.

The project offers no SLA or commercial support. Responses depend on maintainer
availability. Include version, Windows version, installation type, and a
minimal artificial reproduction; do not share real databases or backups.
